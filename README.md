# Eris — Русский

App de estudo de russo (lições diárias, treino de fala e conversa com a Eris).

Publicado com GitHub Pages. Abra no navegador e use "Adicionar à tela inicial" (celular) ou o ícone de instalar (computador). As atualizações chegam sozinhas na próxima abertura.

As chaves de API (ElevenLabs, Azure, Anthropic) ficam só no aparelho, em Configurações. Nada sensível vai para este repositório.
